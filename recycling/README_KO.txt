새싹 지구구조대 4.0 — 교사 목표 설정 + 비밀 OX 별 보상

[바뀐 기능]
- 기본 성공 목표는 3개입니다. 일반 보물 10장 + 비밀 OX 카드 2장 중 서로 다른 카드에서 3개를 성공하면 클리어합니다.
- 비밀 OX 미션을 맞혀도 일반 분리수거 정답과 동일하게 성공 별 1개를 줍니다.
- 각 카드는 한 차례에 한 번만 성공 별을 획득할 수 있습니다. 오답이면 다시 고를 수 있습니다.
- 교사 설정(화면 맨 아래 펼치기) -> 이번 차례 성공 목표 -> 1~12개 선택 -> 목표 적용.
- 성공 목표 변경 시 현재 별 수집 기록을 초기화합니다. 바꾸기 전에 확인창이 나타납니다.
- 성공 화면의 '다음 친구 시작'을 누르면 확인창 없이 새로운 차례가 시작됩니다. 목표는 유지됩니다.
- OX 문제는 16개가 중복 없이 섞여 출제되며, 문제 출제 기록은 차례가 바뀌어도 유지됩니다.

[실행 방법]
1. ZIP 압축 해제 후 index.html을 열어 '그림 선택으로 놀이'에서 테스트하세요.
2. 실제 그림 카메라 인식은 cards/01.png~12.png를 **같은 순서**로 MindAR 공식 컴파일러에 업로드하여 targets.mind를 만들어야 합니다.
   https://hiukim.github.io/mind-ar-js-doc/tools/compile/
3. targets.mind 파일을 index.html과 같은 위치에 두고, 폴더 전체를 GitHub Pages 등 HTTPS에 배포하세요.
4. 카드 인쇄는 treasure_cards_12.pdf (3쪽, 12장)를 사용하세요. 3.0 카드와 그림이 같으므로 기존에 출력한 카드를 다시 인쇄할 필요가 없습니다.
5. 이미지 선택 버전 주요 기능은 PC 브라우저에서 자동 테스트했습니다. 모바일 카메라의 실제 인식은 기기에서 따로 점검이 필요합니다.

[교실 운영]
- 태블릿 1대라면 3명씩 모둠으로 탐색하거나 유아가 한 명씩 돌아가며 카드 3개를 완성하는 활동을 추천합니다.
- 카드를 모두 숨기지 않아도 됩니다. 특별카드까지 12장 중 원하는 수만 교실에 놓아도 됩니다.
- 분리배출 안내는 놀이를 위한 단순 분류이며, 실제 배출 시에는 지역별·재질별 기준을 확인하세요.
