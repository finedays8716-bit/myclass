새싹 지구구조대 v2.0 | 그림인식 보물찾기 웹앱
=====================================

[포함 파일]
- index.html : 새 디자인과 게임 규칙을 적용한 웹앱
- cards/01.png ~ 12.png : MindAR 등록용 그림카드 12장
- treasure_cards_12.pdf : 그림카드 A4 인쇄용 3쪽 (4장씩)
- card_preview.jpg : 카드 미리보기
- assets/ : 웹앱 3D 스타일 그림 자산
- data.json : 목록 확인용

[게임 규칙]
- 일반 보물 10장 중 어떤 6장이든 올바르게 분리하면 성공합니다.
- 특별카드 11번 반짝별, 12번 돋보기는 수집 목표에 포함되지 않습니다.
- 5개 종류: 종이, 종이팩, 플라스틱, 캔, 비닐
- 오답은 벌점 없이 재도전 가능합니다.
- 이미 모은 보물은 중복 수집할 수 없습니다.
- 선생님 설정에서 언제든 기록을 초기화할 수 있습니다.

[카메라로 그림 자체 인식하는 방법]
1) PC 크롬에서 https://hiukim.github.io/mind-ar-js-doc/tools/compile/ 접속
2) cards/01.png ~ 12.png를 반드시 번호 순서로 업로드
3) Start 클릭 후 분석 완료 시 Download 클릭
4) 생성된 targets.mind 파일을 index.html과 같은 폴더에 저장
5) index.html, targets.mind, assets 폴더, cards 폴더를 GitHub Pages 등에 업로드
6) HTTPS로 접속해 태블릿 또는 스마트폰의 카메라 권한 허용
7) '카메라로 찾기' 버튼을 누른 뒤 출력한 그림카드를 비춰 테스트

중요: targets.mind는 현재 패키지에 포함되어 있지 않습니다.
별도의 공식 컴파일러에서 생성해야 카메라 인식이 작동합니다.
첫 사용 시 네트워크 연결이 필요합니다(A-Frame, MindAR CDN).

[카메라가 준비되지 않아도 즐기는 방법]
'그림 선택으로 놀이' 메뉴로 보물 퀴즈와 보상/진행 상태를 즉시 체험할 수 있습니다.

[출력 팁]
- PDF는 100% 크기로 인쇄 / 반사되는 코팅 대신 매트한 종이 사용
- 카드의 테두리, 배경 무늬, 텍스트까지 이미지 인식의 일부입니다.
- 원본 PDF로 출력하고 그림을 심하게 자르거나 수정하지 마세요.
- 인식이 잘 안 되면 빛 반사, 거리, 기울기, 손으로 가린 부분을 조정하세요.

[교사용 안전/교육상 주의]
- 이 프로그램은 3세를 위한 재료별 분리 개념 놀이입니다.
- 투명 음료 페트병은 실제로 별도 수거하는 제도가 있을 수 있습니다.
- 포장재 재질·표시와 지역별 분리배출 규칙을 따르세요.
- 캔 뚜껑 등 날카로운 실제 재료 대신 그림카드만 사용하세요.
