출동! 새싹 지구구조대 — 유치원 3세 그림인식 보물찾기

포함: index.html / cards 폴더에 인식용 그림 6장 / 인쇄용 PDF / 설명서

중요: 이 패키지는 그림 인식에 사용할 targets.mind 파일을 아직 포함하지 않습니다.
MindAR는 그림 6장을 별도 도구로 컴파일해야 합니다. 이 과정 없이는 '카메라로 찾기' 기능이 실행되지 않습니다.
따라서 현재 제공물은 그림 카드와 그림 중심 퀴즈가 완성된 웹앱 + 카메라 인식 연결 코드이며,
이미지 트래킹까지 실기기 검증한 최종 완성품이라고 주장하지 않습니다.

[그림 인식 활성화 (일회 작업)]
1. https://hiukim.github.io/mind-ar-js-doc/tools/compile/ 접속
2. cards/01.png부터 06.png까지 순서대로 한 번에 올리기
3. Start를 눌러 컴파일 완료 후 'Download'로 targets.mind 다운로드
4. targets.mind를 index.html과 같은 위치에 넣기 (카드 이미지 순서 변경하지 말 것)
5. index.html, targets.mind, cards 폴더를 GitHub Pages에 업로드하여 HTTPS로 접속
6. 카메라 버튼을 눌러 인쇄된 실제 카드에 비춰 인식 확인

[시작 전 미리보기]
- index.html을 열고 '그림으로 찾아보기' 선택
- 보물 그림 6종을 터치하여 분리수거 문제 해결, 수집, 축하 화면 확인
- 정답 선택은 이모지가 아닌 직접 그린 SVG 사물 그림 5종으로 표시됨

[교육 운영 메모]
- 종이팩은 일반 종이와 구분, 투명 페트병도 구분하여 5가지 배출 그림 제공
- 지자체별 세부 배출 기준, 오염 여부에 따라 처리 방법은 달라질 수 있음
- 위생상 실제 쓰레기 대신 인쇄 카드를 사용
- 스마트폰/태블릿은 교사가 함께 들고 2~3명씩 탐험하는 방식 권장
- 카드가 잘 인식되지 않으면 밝은 조명, 반사 없는 인쇄, 카드를 화면 안에 크게 잡기
- 같은 기기에서 완료 기록이 저장됨. 교사용 설정에서 초기화 가능

[배포]
GitHub 저장소에 파일 구조 그대로 올리기
  index.html
  targets.mind <- 직접 컴파일하여 추가
  cards/01.png ... cards/06.png
카메라 기능은 HTTPS 배포 및 네트워크 연결이 필요함.
